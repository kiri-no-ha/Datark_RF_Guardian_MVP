# Инженерная концепция: связь, SMS и Wi‑Fi в МЦОД

> Это проектная схема к цифровому двойнику. Не инструкция к самовольному вводу сотового ретранслятора в эфир. Физическую совместимость необходимо подтверждать обследованием и измерениями.

## Объект

По чертежу: 14 × 9 м по наружным габаритам; функциональная площадь 124,7 м²: аппаратный зал — 84,8, энергомодуль — 29,8, технологический тамбур — 10,1 м². В зале — два ряда металлических шкафов. PNG на карте использован без перерисовки; стены/стойки размечены приблизительно.

## 1. Аварийная GSM/SMS-линия (обязательна)

```
СУЩЕСТВУЮЩАЯ GSM АНТЕННА → СУЩЕСТВУЮЩИЙ GSM МОДЕМ → SMS
                            (не подключать к новому RF-тракту)
```

Нельзя предполагать, что широкополосная антенна 790–2700 МГц означает активную работу модема на всех полосах. Для обследования нужны реальные рабочие частоты и измеренный уровень сигнала. Не переносятся, не перенастраиваются, не соединяются с новой DAS-системой.

В интерфейсе статус линии `unmonitored`: «не подключена к телеметрии», а не «SMS гарантированно доставляются». Для фактического контроля нужны данные производителя модема/мониторинга, успешные контрольные SMS и диагностика оператора.

## 2. Сотовая связь персонала — эскиз Repeater + DAS

```
БС оператора ↔ донорная направленная антенна
               ↕
         фильтры / развязка / ограничение мощности
               ↕
       оператором согласованный репитер
               ↕
          RF сплиттер / ответвители
              ↙   ↘           (+ опциональная третья)
       панель №1 панель №2 → панель №3
```

В сценариях программы **2 и 3 — число внутренних панелей**, а не самостоятельных ретрансляторов. Нельзя назначать полосу (в MVP условно LTE 2600) без реального обследования и права её использования. Для промышленного варианта также нужны расчёт обеих направлений (UL/DL), запасы развязки донорной/сервисных антенн, AGC, линейность, фильтрация, выбор кабеля и разветвителей, PIM/IMD, пожарная безопасность.

## 3. Wi‑Fi / VoWiFi

```
Интернет МЦОД → маршрутизатор/межсетевой экран → PoE коммутатор
                                               ↘ Wi-Fi AP №1
                                                ↘ Wi-Fi AP №2
                                                 ↘ Wi-Fi AP №3 (опция)
```

Wi-Fi-инфраструктура решает задачи IP-доступа и потенциально звонков через Wi‑Fi Calling. Поддержка VoWiFi и SMS зависит от мобильного оператора, телефона и сетевых политик. Не следует заменять аварийные GSM-SMS обычными пушами или Wi-Fi без отдельного технического требования.

Расположения точек на карте примерные. Для Wi‑Fi следует отдельно обследовать 2.4 и 5 ГГц, учитывать PoE, доступность монтажа, металл, высоту установки, резервирование интернет-канала и VLAN.

## 4. Российские производители (кандидаты, не спецификация закупки)

- **Eltex**: официальная линейка внутренних Wi‑Fi точек доступа WEP, включая Wi‑Fi 6. Выбирать конкретную модель по требованиям Wi‑Fi/PoE и доступности: https://eltex.ru/catalog/wireless/besprovodnye_tochki_dostupa/
- **VEGATEL**: российский производитель оборудования для усиления сотовой связи, линейки репитеров по частотным диапазонам: https://www.vegatel.ru/

Это лишь ориентиры для диалога с профильным инженером. Не покупать усилители «по названию» без частотного обследования, документации и подтверждения права работы в эфире.

## 5. Что надо замерить перед реальным монтажом

1. Операторы и используемые каналы/частоты внутри и снаружи.
2. Исходная статистика успешности SMS-уведомлений от действующего модема.
3. Доступные места монтажа/прокладки и материалы/высоты перегородок.
4. Мощность/качество DL и UL в контрольных точках.
5. Развязка антенн, отражения, помехи и характеристики RF-компонентов.
6. Для Wi‑Fi: бэкхол, QoS, PoE, фактический канал, насыщенность, roaming/VoWiFi.

## 6. Что показывать на хакатоне

- Варианты расположения на исходном чертеже и сравнение итогов по комнатам.
- Параметры модели и проверку реального изменения карты при перемещении точки.
- Журнал конфигурации и экспорт данных по помещениям.
- Три независимых статуса: **GSM аварийная линия (не трогаем)**, **LTE/DAS (расчёт)**, **Wi‑Fi (расчёт)**.

Модель не доказывает отсутствие интерференции, а подготовленный MVP не заменяет инженерный RF-проект.
