# Сценарий защиты (90–120 секунд)

**Проблема.** Металлический модульный ЦОД экранирует сотовый сигнал. Внутри работают специалисты, но отдельная существующая GSM-линия для аварийных SMS должна остаться независимой и работоспособной.

**Наш подход.** Мы разделили три подсистемы: SMS-модем (не изменяем), LTE/DAS (рассматриваем один репитер и 2–3 внутренние панели) и Wi-Fi/VoWiFi (рассматриваем 2–3 AP, при условии поддержки оператором).

**Демонстрация.** Открываем оригинальный чертёж и включаем LTE/DAS. Показана цветная расчётная карта и отдельная статистика для аппаратного зала, энергомодуля и тамбура. Переключаемся с двух на три панели — карта и проценты пересчитываются. Перетаскиваем панель в другую точку, видим превью; сохраняем, появляется запись в журнале. Переключаемся на Wi-Fi и сравниваем размещение AP.

**Техническая часть.** FastAPI рассчитывает мощность по упрощённой модели потерь с учётом расстояний, перегородок и рядов шкафов. React рисует тепловую карту поверх предоставленного PNG. API хранит сценарии, обеспечивает превью и журнал изменений. Никаких внешних геоинформационных API для работы в РФ не требуется.

**Границы результата.** Цвета — расчёт, не RF-измерение. Статус аварийной GSM-линии неизвестен до подключения её мониторинга. Для перехода к промышленной эксплуатации нужен совместный инженерный проект с оператором и проверка ЭМС/PIM/IMD, обоих направлений связи, а также Wi-Fi покрытия.

**Финальная фраза:** «Мы сделали управляемый цифровой двойник, который позволяет сравнить варианты до закупки и монтажа и аккуратно отделяет прогноз от фактических измерений».
