# Datark RF Guardian — обоснование аппаратной архитектуры

## Задача

Обеспечить персонал связью в экранированном модульном ЦОД, не изменяя существующую антенну и GSM-модем аварийных SMS. Для объекта использован предоставленный PNG-план 14 × 9 м, включающий аппаратный зал (84,8 м²), энергомодуль (29,8 м²) и тамбур (10,1 м²).

## 1. Внешний сегмент

**Направленная донорная антенна** вне металлического контура МЦОД: предпочтительна при известном секторе базовой станции, чтобы повысить селективность по направлению. Выбор возможен только после проверки реально используемых оператором полос и внешнего уровня сигнала. Антенна существующих SMS-уведомлений не используется совместно с новой системой.

## 2. Промежуточный сегмент: ЭМС

Новый отдельный RF-тракт включает частотную селекцию (BPF и совместимый дуплексер / диплексер), согласованный репитер с AGC/ALC и защитой от самовозбуждения. Проверяется не только подавление внеполосных сигналов, но и:

- развязка донорной и сервисных антенн и устойчивость усиления;
- PIM пассивных кабелей, соединителей и делителей;
- IMD усилительного тракта и побочные излучения;
- влияние на фактические диапазоны и качество приёма существующего GSM-модема;
- uplink/downlink и реальные уровни мощности;
- выполнение тестовых аварийных SMS до/после подключения.

**Утверждать «помех нет» без натурных измерений нельзя.** Пространственное разделение и фильтры — меры снижения риска, не доказательство полной ЭМС.

## 3. Внутренний сегмент

Один репитер -> система делителей / ответвителей -> 2–3 панельные антенны DAS по зонам. В интерфейсе можно указать другое количество внутренних антенн, но при изменении количества необходимо пересчитать потери распределения, баланс мощности и требования к развязке. Несколько панельных антенн не эквивалентны нескольким самостоятельным репитерам.

## 4. Wi-Fi и аварийная SMS-линия

Wi-Fi: отдельная Ethernet/PoE-сеть с точками доступа. VoWiFi возможен только при поддержке оператором, устройством и наличии интернет-канала. Существующая SMS-линия: старая GSM-антенна -> старый GSM-модем -> тревожные уведомления; никаких изменений конфигурации или электрического подключения к новой DAS.

## 5. Результат программного MVP

React отображает PNG и модель покрытия; Python API сохраняет сценарии, считает условные уровни, формирует инженерный анализ и отдельный текстовый отчёт по объекту. Реальный подбор моделей, сертификация, измерения ЭМС, паспорт линии и допуск оборудования пока вне MVP.
